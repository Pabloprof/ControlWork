Manual de Conversión a Aplicación Android

Convierte tu sistema Servicio Integral Informático en una App nativa instalable en tu celular o tablet Android.

Método 1 (Más Rápido)

Instalación Directa como PWA (Web App)

No requiere compilar código APK. Funciona offline, guarda tus datos localmente en tu celular y se abre como una app normal.

  1. 1 Sube este archivo HTML a un servicio gratuito (ej. GitHub Pages, Netlify o Vercel) para obtener un link web HTTPS.
  2. 2 Abre ese link desde el navegador Google Chrome en tu teléfono Android (Pablo Sepúlveda - 2984-151895).
  3. 3 Toca el menú superior derecho de Chrome (los 3 puntos) y selecciona "Instalar aplicación" o "Agregar a la pantalla principal".
  4. 4 ¡Listo! Se creará el acceso directo con el icono del sistema en tu escritorio Android como si fuera una app descargada de Google Play.
Método 2 (Generar archivo .APK)

Empaquetado Nativo con PWABuilder

Si necesitas un archivo `.apk` real para instalar manualmente o subirlo a la Play Store.

  1. 1 Sube la web a internet (Netlify, Vercel o GitHub) para tener tu URL pública.
  2. 2 Entra desde tu PC a pwabuilder.com y pega tu URL.
  3. 3 Haz clic en "Generate" en la sección de Android. Te generará un paquete con el archivo Manifest y el wrapper de Bubblewrap.
  4. 4 Descarga tu archivo .apk o .aab firmado y pásalo a tu celular o súbelo a Google Play Console.

Consejos Útiles para tu Trabajo Técnico

  • Respaldo de Datos Usa siempre el botón de Respaldar Datos en la barra superior para descargar un archivo JSON semanalmente y guardarlo en Google Drive.
  • Uso sin Conexión Al instalar como PWA, la aplicación guarda toda la base de clientes y finanzas en la memoria interna de tu celular, funcionando perfectamente en zonas rurales sin señal.
  • Contacto Directo Tus clientes podrán ver tu número de WhatsApp profesional (2984-151895) integrado directamente en el encabezado de la app.
